# Atelier Service Register API

Backend API for the Atelier Digital Service Register application.

## Features
- User Authentication (Admin & Technician)
- Order Management (Create, Update, Track)
- 3rd Party Vendor Management (Outsourcing)
- Dashboard Analytics & Reporting
- Customer Management
- PDF Invoice Generation

## Tech Stack
- Node.js
- Express.js
- MongoDB (Mongoose)
- JWT Authentication
- Swagger UI (Documentation)

## Setup
1. Install dependencies: `npm install`
2. Create `.env` file with required variables.
3. Run development server: `npm run dev`

## API Documentation
Access Swagger documentation at `/api-docs` when running the server.
